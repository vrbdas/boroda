# Ленстройкомплектация — тестовое задание frontend-разработчика

Главная страница корпоративного сайта компании «Ленстройкомплектация» (добыча и обработка камня).

На фоне реализован полноэкранный слайдер, при прокрутке происходит перелистывание целыми секциями (fullpage scroll). Цвет текста динамически меняется в зависимости от текущего фона. Сайт адаптирован под мобильные устройства.

## 🎯 Основной функционал

- Фон в виде полноэкранных слайдов
- Перелистывание страницы по секциям (fullpage scroll)
- Динамическая смена цвета текста в зависимости от фона
- Адаптивная верстка
- Чистая и семантичная структура кода

## 🔧 Использованные технологии

- HTML
- CSS / SCSS
- JavaScript (Vanilla)
- Методология БЭМ
- Gulp
- Webpack
